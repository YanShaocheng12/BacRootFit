# BacRootFit v1.0.0

Manuscript-aligned resource: 14,505 complete proteins, experimental labels and evidence tracking, repaired homology partitions, 340-configuration development results and separate development/deployment SVM bundles. Public CLI supports checked raw-feature inference, pinned ProtT5 FASTA extraction, fixed-fold training, locked-threshold evaluation and data integrity verification.

The data archive includes the historical H3 duckweed surface-colonization transfer cohort separately from formal training data. No post-manuscript candidate source was added to the training database. The lightweight feature archive supplies raw ProtT5 means sufficient for reproducing the selected model; the full five-encoder residue collection remains a separate large-data requirement.

Archive identities and version-specific hashes are listed in release_manifest.json. Code is MIT; original curation contributions are CC BY 4.0; upstream terms remain applicable. Zenodo DOI is pending actual deposition.
