# BacRootFit v1.0.0

Complete code, data and pretrained models for the BacRootFit resource.

- 14,505 complete proteins from 21 studies, with experimental labels and source evidence.
- Pretrained model bundles, installation instructions and FASTA prediction commands.
- Fixed partitions, internal/H3 bootstrap groups and reproducible evaluation helpers.
- ProtT5 mean features, stored comparison results and per-encoder feature generation commands.
- Searchable database with readable evidence descriptions and stable record identifiers.

The separate H3 duckweed surface-colonization cohort is distributed for transfer evaluation. See [grouping history](docs/GROUPING_HISTORY.md) for the provenance of the released partitions.
