# Resource distribution

- [Database browser](https://yanshaocheng12.github.io/BacRootFit/)
- [Software v1.0.1](https://github.com/YanShaocheng12/BacRootFit/releases/tag/v1.0.1)
- [Data and model assets v1.0.0](https://github.com/YanShaocheng12/BacRootFit/releases/tag/v1.0.0)

The software release includes cohort groups, fixed configurations and reproduction helpers. Its manifest downloads the matching v1.0.0 data, model, feature and results assets. Original data/model ZIPs remain unchanged. Users can obtain a complete versioned source snapshot without copying additional files from a development branch.

The website provides database search, experimental evidence and data downloads. Model prediction runs through the software linked from the site. Source-study publications remain linked as experimental evidence.

Installation is documented in [INSTALLATION.md](INSTALLATION.md); analysis requirements are in [REPRODUCIBILITY.md](REPRODUCIBILITY.md). Software/database citation metadata are supplied in `CITATION.cff`. Original code is MIT; original curation contributions are CC BY 4.0; upstream terms remain applicable.

Maintainers can find hosting and release procedures in [MAINTAINERS.md](MAINTAINERS.md).
