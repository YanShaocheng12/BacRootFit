# Resource distribution

- [Database browser](https://yanshaocheng12.github.io/BacRootFit/)
- [BacRootFit v1.0.0: code, data and models](https://github.com/YanShaocheng12/BacRootFit/releases/tag/v1.0.0)

The single release includes complete source code, cohort groups, fixed configurations and reproduction helpers. Its data, model, feature and results archives are installed by `bacrootfit assets`. No files need to be copied from another branch or release.

The website provides database search, experimental evidence and data downloads. Model prediction runs through the linked software. Source-study publications remain linked as experimental evidence.

See [installation](INSTALLATION.md), [reproducibility](REPRODUCIBILITY.md) and [maintainer procedures](MAINTAINERS.md). Resource citation metadata are in `CITATION.cff`. Original code is MIT; original curation contributions are CC BY 4.0; upstream terms remain applicable.
